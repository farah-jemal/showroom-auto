# ShowroomAuto

Application Angular de showroom automobile : liste de voitures, recherche par marque et fiche détail.

## Démo en ligne
https://farah-jemal.github.io/showroom-auto/

## Lancer le projet en local
npm install
ng serve

Puis ouvrir http://localhost:4200/

## Déploiement
ng deploy --base-href=/showroom-auto/
